# Plantilla `.foodpack`

Incluya `food.json` y, de forma opcional, `model.glb`, `icon.*` y audio. La digestibilidad específica no pertenece a `food.json`: debe distribuirse como un `SpeciesFoodProfile` independiente.

Valide contra `Schemas/` antes de comprimir el contenido como ZIP y cambiar la extensión a `.foodpack`.
