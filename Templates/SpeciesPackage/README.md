# Plantilla `.speciespack`

Copie aquí `species.json`, `digestive_graph.json`, `model.glb`, opcionalmente `digestive_system.glb`, y una carpeta `organs/<organ-id>/organ.json` por cada órgano declarado. Valide contra `Schemas/` antes de comprimir el contenido de esta carpeta como ZIP y cambiar la extensión a `.speciespack`.

Los modelos se omiten deliberadamente en la plantilla del repositorio.
